esp_brookesia_phone 프로그램 구조 정리

대상 소스: work/esp_brookesia_phone / 진입점: main/main.cpp

현재 첫 화면 앱은 main.cpp에서 phone->installApp(...)로 등록됩니다. 기본 등록 앱은 8개이며, SD 카드가 정상 마운트되면 Video Player가 추가되어 9개가 될 수 있습니다.

1. 전체 실행 흐름

1) NVS 초기화nvs_flash_init()로 설정 저장소를 준비합니다.
2) 파일 시스템bsp_spiffs_mount()로 내부 SPIFFS를 마운트하고, SD 카드는 있으면 마운트합니다.
3) 오디오bsp_extra_codec_init()로 코덱/I2S 계열 장치를 준비합니다.
4) LCD/LVGLbsp_display_start_with_config()로 화면 버퍼와 LVGL 포트를 시작합니다.
5) Phone ShellESP_Brookesia_Phone 객체를 만들고 1024x600 dark stylesheet를 적용합니다.
6) 앱 등록각 앱 객체를 생성하고 installApp()으로 런처에 등록합니다.

2. 앱 프레임워크 구조

각 앱은 대부분 ESP_Brookesia_PhoneApp을 상속합니다. Brookesia Phone Shell이 홈 화면, 앱 런처, 상태바/내비게이션바, 앱 전환을 관리하고, 개별 앱은 LVGL 화면과 실제 동작만 담당하는 구조입니다. 

class Calculator: public ESP_Brookesia_PhoneApp {
public:
    bool init(void) override;   // 앱 UI/리소스 생성
    bool run(void) override;    // 앱 실행, 화면 표시
    bool pause(void) override;  // 다른 앱으로 전환될 때 일부 앱에서 사용
    bool resume(void) override; // 다시 돌아올 때 일부 앱에서 사용
    bool back(void) override;   // 하단 내비게이션/뒤로가기
    bool close(void) override;  // 앱 종료 및 리소스 정리
};

앱 목록 헤더는 components/apps/apps.h에 모여 있고, components/apps/CMakeLists.txt는 components/apps 아래의 C/C++ 파일을 재귀적으로 모두 빌드에 포함합니다.

8 Echo NewApp components/apps/new_app 새 앱 템플릿을 기반으로 만든 Echo 앱입니다. Start/Stop 버튼으로 I2S 마이크 입력을 읽어 스피커로 다시 출력합니다.
옵션 Video Player AppVideoPlayer components/apps/video_player SD 카드가 마운트된 경우에만 추가됩니다. /sdcard/mjpeg 아래의 MJPEG/AVI 계열 파일을 재생합니다.

6. 리소스와 저장 위치

항목 위치/역할
SPIFFS spiffs 폴더가 플래시에 올라갑니다. 이미지, 음악, 2048 효과음 같은 고정 리소스에 사용됩니다.
SD 카드 마운트 성공 시 Video Player 앱이 추가됩니다. 비디오 파일은 코드상 /sdcard/mjpeg 경로를 사용합니다.
NVS Settings 앱의 Wi-Fi/볼륨/밝기 설정, 2048 최고 점수 저장에 사용됩니다.
앱 아이콘 각 앱 폴더의 assets 또는 UI image 파일에서 LV_IMG_DECLARE(...)로 참조됩니다.

7. 새 앱을 추가하는 방법

  1. components/apps/my_app 같은 새 폴더를 만듭니다.
  2. ESP_Brookesia_PhoneApp을 상속하는 C++ 클래스를 작성합니다.
  3. init()에서 LVGL 화면과 버튼/라벨/이벤트를 만들고, run()에서 화면을 로드합니다.
  4. 필요하면 pause(), resume(), back(), close()에서 task, timer, audio, camera 리소스를 정리합니다.
  5. components/apps/apps.h에 새 앱 헤더를 include합니다.
  6. main/main.cpp에서 객체를 만들고 phone->installApp(my_app)를 호출합니다.

8. 현재 소스에서 특히 볼 부분

  • main/main.cpp: 부팅 초기화, Phone Shell 생성, 앱 설치 순서.
  • components/apps/apps.h: 프로젝트 앱 헤더 목록.
  • components/apps/CMakeLists.txt: 앱 소스 자동 수집 및 의존 컴포넌트.
  • components/apps/setting/Setting.cpp: Wi-Fi, 밝기, 볼륨, NVS 설정 처리.
  • components/apps/new_app/NewApp.cpp: 사용자가 기능을 추가하기 가장 쉬운 예제 앱.
정리: 이 펌웨어는 “ESP-IDF BSP 초기화 + LVGL + ESP Brookesia Phone Shell + 개별 앱 클래스” 구조입니다. 첫 화면의 8개 앱은 런처 데이터 파일에서 자동 생성되는 것이 아니라, main.cpp에서 C++ 객체를 직접 생성하고 등록하는 방식입니다.
